Онлайн-функции Android

Поиск музыки и воспроизведение доступных онлайн-превью работают через музыкальный каталог. Полноценная загрузка YouTube через yt-dlp не входит в Android-сборку.

Для локальной музыки доступны системный выбор файлов и папок, чтение тегов и встроенных обложек, библиотека, виртуальные плейлисты и фоновое воспроизведение.

YouTube и yt-dlp

Поиск, воспроизведение и скачивание треков с YouTube через yt-dlp.

Проверка не выполняласьНажмите «Проверить».

JS runtime для дополнительных проверок YouTube будет определён автоматически.

Chrome и Edge шифруют cookies через App-Bound Encryption, поэтому yt-dlp не может их прочитать (ошибка DPAPI). Надёжнее всего Firefox или файл cookies.txt.

Для MP3 нужен FFmpeg. Crimson автоматически ищет FFmpeg рядом с yt-dlp и в PATH; если его нет, трек сохранится без перекодирования.

Кэш метаданных

Результаты MusicBrainz/iTunes/Deezer сохраняются локально, чтобы повторно не запрашивать уже проверенные файлы.

После очистки данные останутся в музыкальных файлах, а кэш будет заполнен заново в фоновом режиме.

Инструменты библиотеки

Быстрые проверки локальной коллекции.

Crimson различает точные копии и вероятно одинаковые записи; для одинаковой записи показывает формат/качество и более предпочтительный файл.

Восстановление библиотеки

Crimson автоматически создаёт резервную копию JSON перед сохранением. Используйте её, если основной файл библиотеки повредился.

Восстановление заменяет текущую библиотеку последней доступной резервной копией.
